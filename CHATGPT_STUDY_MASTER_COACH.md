## 📝 THE 5/5 MUMBAI UNIVERSITY EVALUATOR FRAMEWORK

When writing any 5-mark answer in Mumbai University B.Sc Computer Science examinations, evaluators grade against this 4-step rubric. Rohit must train with ChatGPT to produce this exact output in 8 minutes flat:

### Step 1: Formal Definition (1.0 Mark)
- **Format**: Exactly 2 to 3 sentences in plain English.
- **Rule**: Must include core industry-standard terminology (e.g. *"Divide-and-conquer"*, *"Atomic transaction"*, *"Transitive functional dependency"*, *"SOP minimization"*).
- **Presentation**: Bold key terms with a black or blue pen.

### Step 2: Block Architecture / Schema / Circuit Diagram (1.5 Marks)
- **Format**: Clean rectangular ASCII or pen-and-scale diagram.
- **Rule**: Every box must have a title, input/output labels, and directional arrows.
- **Examples**:
  - DAA: Partition tree or recursion tree.
  - DBMS: 3-Tier ANSI/SPARC schema or E-R entity diamonds.
  - Digital Systems: Logic gates with inputs $A, B$ and outputs $S, C_{out}$.
  - CPU: PC $\rightarrow$ MAR $\rightarrow$ Memory $\rightarrow$ MDR $\rightarrow$ IR $\rightarrow$ ALU.

### Step 3: Core Working & Theory (1.5 Marks)
- **Format**: Exactly 4 bullet points (numbered 1 to 4).
- **Rule**: Never write a block paragraph. Evaluators look for 4 distinct points to tick off $4 \times 0.375 = 1.5$ marks:
  1. *Initialization / Base State*
  2. *Processing / Inner Loop Mechanism*
  3. *State Transition / Logic Rules*
  4. *Termination / Complexity Edge Case*

### Step 4: Code Snippet / Mathematical Derivation / Formula (1.0 Mark)
- **Format**: 5 to 10 lines of syntactically valid code or formula.
- **Rule**: Include comments, variable definitions, and time/space complexity ($O(1)$, $O(n \log n)$, etc.).
