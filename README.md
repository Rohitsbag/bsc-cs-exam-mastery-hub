# 🎓 B.Sc Computer Science NEP 2020 — 25+ Marks Mastery Hub & Interactive Lab

An interactive, responsive single-page web application and mastery hub designed for **Mumbai University / RD National College (Autonomous)** B.Sc Computer Science students. Built with "The Steve Jobs" clean & minimalist design system, KaTeX mathematical typesetting, dynamic visual simulation sandboxes, and an interactive 30-day Google Calendar-style daily study engine.

---

## 🌟 Key Features

### 1. 📅 30-Day Master Interactive Calendar (Sept 1 – Sept 30, 2026)
- **Daily 3-Block Interleaved Study Engine (7.5 Hours/Day):**
  - `🌅 Morning Block (8:00 AM – 10:30 AM)`: Deep Core CS Theory & Architecture from scratch.
  - `☀️ Afternoon Block (2:00 PM – 4:30 PM)`: Hands-on Code, Shell Scripting & Descriptive Statistics.
  - `🌆 Evening Block (6:30 PM – 8:30 PM)`: High-Yield Scoring Electives & Management.
  - `🌙 Night Recall (10:00 PM – 10:45 PM)`: Active Spaced Repetition Flashcard drills.
- **3 Interactive Calendar Views:**
  - `Month Grid View`: 30-day interactive calendar with subject badges.
  - `Day Inspector`: Step-by-step checklist with **1-click curated YouTube video links** and live progress tracking (`0% → 100%`) persisted via `localStorage`.
  - `Week Matrix`: 4-phase milestone tracking.

### 2. 🧪 6 Interactive Visual Simulation Labs
- **DAA Sorting Visualizer:** Real-time step-by-step Divide-and-Conquer Merge Sort and Quick Sort with comparison counters.
- **Logic Gates & Dynamic Truth Table:** Interactive AND, OR, NAND, NOR, and XOR gates with dynamic table highlighting.
- **Von Neumann CPU Instruction Stepper:** Trace register data transfers (`PC → MAR → MDR → IR → AC`) across Fetch, Decode, and Execute clock cycles.
- **DBMS Normalization Sandbox:** Interactive 1NF, 2NF, and 3NF normalization sandbox demonstrating anomaly elimination.
- **Live Descriptive Statistics Calculator:** Computes Mean, Standard Deviation (\(\sigma\)), Variance (\(\sigma^2\)), and Karl Pearson correlation coefficient (\(r\)) in real-time.
- **Linux chmod Octal Calculator:** Live octal and symbolic permission calculator (e.g., `chmod 755 script.sh`).

### 3. 📚 Complete 16-Course Syllabus & 5/5 Evaluator Formula
- All 16 courses across Semester 1 and Semester 2 with NEP 2020 course codes, unit breakdowns, formulas rendered with KaTeX, ASCII architecture diagrams, and code snippets.
- **The 5/5 Evaluator Formula:**
  1. *Formal 2-line Definition (1.0 M)*
  2. *ASCII Architecture Diagram (1.5 M)*
  3. *4 Numbered Technical Bullets (1.5 M)*
  4. *Code / Formula Snippet (1.0 M)*

### 4. 🗂️ 3D Active Recall Flashcards
- High-yield exam question cards with 3D flip animations and 5/5 model answers.

### 5. 💼 Master Academic & Financial Dossier
- Includes `dossier.html` for complete financial fee receipts, loan records, MahaDBT reimbursement tracking, and parent briefing scripts.
